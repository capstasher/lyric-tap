OpenShot

  1. Drop your song and background clip on the timeline.
  2. Effects tab, drag Caption onto the clip the words should sit on.
  3. Click the effect's green marker, select the placeholder text, paste.
  4. Position and size with the effect's margin properties, never the Transform tool.

Cue times are measured from the start of the clip carrying the effect, not the timeline. Use Shift to compensate for a trimmed head.

MiniLyrics

Save the .lrc beside the audio file with the same base name, or in whichever folder you've set under the lyrics-download preferences. For a ripped CD that means matching each track file exactly.

Shift bakes the correction into every timestamp. The offset tag leaves the stamps alone and asks the player to compensate, which is reversible but depends on the player honouring it. Positive values are meant to make lines appear earlier; test it, since players disagree about the sign.
